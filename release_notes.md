# LS Pass v1.0.0

**100% local, client-side, zero-knowledge Bitwarden-style password manager for Android.**

### Highlights
- **Zero-Knowledge Architecture**: Vault data (passwords, TOTP secrets, identities, SSH keys, passkeys) is encrypted on-device with AES-256-GCM using Argon2id key derivation.
- **100% Offline**: Local Room database with zero server dependency, zero tracking, zero telemetry.
- **Biometric Unlock**: Instant fingerprint and face unlock supported via Android Keystore.
- **Autofill Service**: Seamless credential autofill for apps and web browsers.
- **Import & Backup**: Supports Bitwarden CSV import and AES-256-GCM encrypted vault backup exports.
